A partire da un file .gcode generato da Bambu Studio per la stampante 3D, si scrive uno script che legge riga per riga i comandi di movimento ed estrae le coordinate x, y e z in modo da calcolare la distanza completa percorsa dall'estrusore. Questo programma serve a me stesso per imparare la gestione di file di testo, le stringhe ed altro.
